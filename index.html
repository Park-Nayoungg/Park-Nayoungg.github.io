영상 렌더링 서버 부하

문제
1주 만에 출시한 브이로그 기능에서 FFmpeg 렌더링이 몰리면 서버 부하가 커졌습니다.
해결
렌더링을 전용 비동기 Executor로 분리하고 동시 실행 수·대기 큐·스레드 수를 제한했습니다. 큰 파일은 S3 Presigned URL로 바로 올리게 했습니다.
기능 유지하며 부하 완화

쓸모없이 반복되던 집계

문제
랭킹 집계가 10분마다 하루 144번 돌았고, 제출이 없는 기간에도 스냅샷이 1,300건 넘게 쌓였습니다.
해결
갱신을 하루 1회로 바꾸고 점수·추세 계산은 테스트 코드로 검증했습니다.
연산 약 99% 감소

  • 질문 문장의 조사(을/를, 이/가)를 단어에 맞게 자동 변환
  • 탈퇴 계정 로그인, 학생증 인증 거절 시 이유를 안내

  • 제출 파일을 다운로드 없이 미리보기 (권한 확인 후 5분 만료 링크)
  • 실수로 탈퇴해도 복구할 수 있는 30일 유예 탈퇴
